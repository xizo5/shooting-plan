先把话聊清楚，

用一句话说清你想怎么拍，附上模特图、场景图也行。AI 不急着出方案——先跟你把风格、服装、道具、动作聊拢，归纳成一份拍摄约定，你点头之后才生成。

一 / 流程

三步走，聊在前，拍在后

大部分 AI 出图工具是「输入 → 等结果」。拍摄这件事不一样：风格没谈拢就生成，出来的一定得返工。所以这里把「聊」单独做成一步。

1

说想法

描述你想拍什么，最多附 4 张参考图——模特图或场景图都行。机位会贴着场景图里的真实站位写，动作会贴着模特图的气质来。

brief · 自由输入
2

定约定

AI 逐字流式地把风格、服装、道具、动作跟你聊一遍。聊完归纳成一张卡：风格调性、服装、道具、动作与情绪、其他约束，五个字段逐条可改。

consensus · 可复核可修改
3

出方案

约定锁死风格，AI 并行展开成 3 套同一调性、不同场景的完整文字策划，顶部切换对比。每套必带 1 个备用场景——下雨、人多、光线不对时直接换。

plan · 3 套并行

二 / 能力

它替你省掉的那些返工

不追求「一句话出大片」。它解决的是真实的拍摄现场问题：到了地方不知道手放哪、光线不对没有 Plan B、摄影师问你要什么风格你说不上来。

聊的时候是逐字出的stream
讨论环节走 SSE 流式输出，字是一个一个蹦出来的，不用盯着空白等一整个段落。中文字符被网络切成半个也不会乱码——只按换行切分，残缺的行留在缓冲区等下一块。
参考片按需生成on demand
看完文字方案，觉得哪个画面拿不准再点那一下。不自动烧钱，也不把 3 套 × 每套好几个画面的图一次性全生成出来堆在屏幕上。
没配生图也能用fallback
内置一套简笔画姿势库，零成本、永远兜底。生图模型是可选增强——不配就是纯文字策划加简笔画，功能不失血。
存成长图带去现场export
整套策划导出成一张竖版长图，生成好的参考片会一起排进每个画面。手机上翻着就能照着拍，不用在现场重新登录某个网站。
手抖点不出两套guard
生成按钮用同步锁互斥，不是只看按钮的禁用态。React 的状态更新是异步的，同一批点击里禁用态挡不住第二次——锁能。按下立刻翻到第 3 步，等待动画独占一屏，完成或失败都有明确反馈。
模型看不了图就脱图重试degrade
不是所有模型都支持多模态。带图请求失败时自动去掉图片重试一次，并明确告诉你「当前模型看不了图」，而不是丢一个报错让你猜。

三 / 部署

clone 下来，配好 Key，跑起来就是你的

没有后端，没有账号，没有额度。浏览器直连厂商的 OpenAI 兼容接口，Key 由 .env 在构建期注入。

# 需要 Node 18+
git clone https://github.com/xizo5/shooting-plan
cd shooting-plan
npm install
cp .env.example .env   # 然后填自己的 API Key
npm run dev            # 浏览器打开提示的地址
注意 Vite 会把 VITE_* 变量明文编译进 JS 产物，dist/ 里能直接搜到 Key。自己 clone 自己跑没问题（填的是你自己的 Key），但不要把带 Key 的 dist/ 部署到公开地址——那等于公开自己的 Key。所以这个站点只是介绍页，不提供在线试用版。
